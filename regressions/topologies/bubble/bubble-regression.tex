\section*{Self-Energy Bubble Regression}

Package-level standalone self-energy bubbles. These examples use the public
\verb|\BubbleCorr| API, not raw mockup drawing.

\[
\begin{array}{cc}
  \bubblecell{clean default}{
    \BubbleCorr[
      show-momenta=false
    ]
  }&
  \bubblecell{momenta}{
    \BubbleCorr[
      show-momenta=true,
      bubble-external-line={ewboson,endcap},
      momentum-labels={p,p},
      bubble-momenta={\ell,p-\ell}
    ]
  }
\end{array}
\]

\[
\begin{array}{cc}
  \bubblecell{endpoint indices}{
    \BubbleCorr[
      show-momenta=false,
      bubble-external-line={ewboson,endcap},
      bubble-a-indices={a,b},
      bubble-b-indices={c,d}
    ]
  }&
  \bubblecell{flat endpoint shorthand}{
    \BubbleCorr[
      show-momenta=false,
      bubble-external-line={ewboson,endcap},
      bubble-endpoint-indices={\alpha,\beta,\rho,\sigma},
      bubble-index-size=script
    ]
  }
\end{array}
\]
